# 💬 ReChat

> Современный, быстрый и кастомизируемый Twitch-чат и оверлей виджетов для стримеров на Windows.

[![Release](https://img.shields.io/github/v/release/Or1GG1n/ReChat?color=amber&label=Version)](https://github.com/Or1GG1n/ReChat/releases)
[![Platform](https://img.shields.io/badge/Platform-Windows-blue)](https://github.com/Or1GG1n/ReChat)

---

## ⚡ Особенности

* 🎮 **Прозрачный игровой оверлей** — режим поверх всех окон (`Ctrl+Shift+G`) с прозрачным фоном для чтения чата прямо во время игры.
* 🎨 **Стильные темы для OBS**:
  * **Avatar-BG**: аватарки зрителей в качестве размытого градиентного фона сообщений.
  * Музыкальные виджеты: винил, кассета, ретро 98, киберпанк и др.
* 😄 **Полная поддержка эмоутов и бейджей** — Twitch, 7TV, BetterTTV (BTTV) и FrankerFaceZ (FFZ).
* 🗣️ **Встроенный TTS (озвучка сообщений)** — синтез речи через Yandex SpeechKit или системные голоса Windows с гибкой фильтрацией команд и ботов.
* 🔌 **Локальный веб-сервер (SSE)** — оверлеи в OBS обновляются мгновенно и без задержек.

## 🚀 Быстрый старт

1. Перейдите во вкладку [**Releases**](https://github.com/Or1GG1n/ReChat/releases) и скачайте свежую версию `ReChat.exe` (или архив).
2. Запустите `ReChat.exe`.
3. Введите название вашего Twitch-канала в настройках.

---

## 🎥 Подключение к OBS Studio

1. В OBS добавьте источник типа **«Браузер»** (Browser Source).
2. В поле **URL** укажите локальную ссылку нужного виджета:
   * **Чат (Avatar-BG):** `http://localhost:3500/chat?theme=avatar-bg`
   * **Чат (Стандартный):** `http://localhost:3500/chat`
   * **Музыкальный плеер:** `http://localhost:3500/music?theme=vinyl`
3. Выставите желаемую ширину и высоту (например, `450x700`).

---

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
| :--- | :--- |
| `Ctrl + Shift + G` | Включить / выключить прозрачный игровой режим поверх окон |
| `Escape` | Пропустить текущее зачитываемое TTS-сообщение |
